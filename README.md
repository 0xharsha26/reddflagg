# 🛡️ REDDFLAGG: Multi-Mode Threat Intelligence Platform

REDDFLAGG is a comprehensive phishing detection and threat intelligence platform that analyzes suspicious text, URLs, screenshots (OCR), and QR codes.

## 🚀 Hugging Face Space Configuration
This Space is configured as a standalone **Docker Container** running:
* **Backend:** FastAPI (Python 3.12)
* **Frontend:** Sleek Cyber-Dark Vanilla CSS/JS console
* **System Binaries:** Tesseract-OCR, libzbar0, and Mesa OpenGL/Glib bindings for OpenCV.
